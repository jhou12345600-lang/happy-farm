# 歡樂偷菜農場

網頁版農場遊戲：種菜、養動物、養寵物、加好友、互相偷菜、多人即時連線。

開始玩：https://jhou12345600-lang.github.io/happy-farm/

## 功能
- 農場：9 種作物（含牧草）、澆水除草除蟲、化肥、擴建土地
- 牧場：雞、鴨、兔子、小豬、綿羊、乳牛，餵食後生產雞蛋、鴨蛋、兔毛、松露、羊毛、牛奶
- 寵物：小黃狗、柴犬、哈士奇（咬小偷）、小橘貓（抓蟲）
- 好友：偷菜、偷產品、幫忙、惡作劇、排行榜、找玩家
- 多人連線：在線狀態、看到誰在你家、頭上說話泡泡
- 每日任務、幸運轉盤、每日簽到、改名字

## 技術
- 後台：Firebase（Authentication 帳號密碼 + Firestore）
- `firestore.rules`：資料庫安全規則（已發布到 Firebase 專案 happy-farm-a5ff9）
- 網址加 `?local&speed=60` 可用單機加速模式測試
